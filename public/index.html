How it works

  1. Add your script - paste it, upload it, or type its file path.
  2. Pick a model - Grok or OpenRouter (your key is read from the saved setup).
  3. Click Generate - you get test cases, edge cases and risks in about a minute.
  4. Download or revisit - export CSV / Markdown / JSON. Every run is logged under History & Logs with time and script details.
